# Glosario del Dominio

| Término | Definición |
|---------|------------|
| **Paciente** | Persona física que recibe atención médica. Datos: nombre, email, teléfono, fecha de nacimiento, dirección. |
| **Cita** | Evento programado entre un paciente y el consultorio en una fecha y hora determinadas. Estados: Programada, Completada, Cancelada. |
| **Informe Médico** | Documento clínico asociado a un paciente que contiene título, contenido textual, doctor responsable y fecha. |
| **Dashboard** | Pantalla principal que muestra resumen de pacientes, citas e informes con enlaces de navegación. |
| **SDD** | Spec-Driven Development — metodología donde las especificaciones formales guían la implementación. |
| **MCP** | Model Context Protocol — protocolo que permite a asistentes de IA interactuar con herramientas externas. |
