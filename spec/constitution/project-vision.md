# Project Vision

## Visión

Construir un sistema de gestión de consultorio médico moderno, rápido y fiable que sirva como prueba de concepto para demostrar integración entre Angular, .NET y MongoDB, con validación automatizada mediante Playwright.

## Alcance

### Incluye (MVP)
- Gestión de pacientes (alta, listado, edición, eliminación)
- Gestión de citas (creación, listado, cancelación)
- Gestión de informes médicos (creación, visualización, eliminación)
- Dashboard con métricas básicas
- Tests E2E que validan navegación y UI
- Servidor MCP para automatización mediante IA

### Excluye (fuera de alcance)
- Autenticación y autorización de usuarios
- Historial de cambios / auditoría
- Notificaciones por email
- Integración con sistemas externos
- App móvil nativa

## Objetivos

1. Validar la integración Angular 22 + ASP.NET Core 10 + MongoDB
2. Demostrar el flujo SDD con Playwright como validador de especificaciones
3. Servir como base reproducible para futuros desarrollos
