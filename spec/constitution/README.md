# Constitution

La **Constitución** del proyecto define los acuerdos fundacionales, reglas y estándares que guían el desarrollo. Todo cambio en el código debe alinearse con estos documentos.

## Documentos

| Archivo | Propósito |
|---------|-----------|
| `project-vision.md` | Visión, alcance y objetivos del proyecto |
| `glossary.md` | Glosario del dominio con términos y definiciones |
| `spec-standards.md` | Estándares para escribir y mantener especificaciones |
